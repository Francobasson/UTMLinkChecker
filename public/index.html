WEBSITE DIAGNOSTICS

Know which pixels are present.

Check a website for common tracking tags. Use browser mode to watch for tracking requests during a page visit.

Checks Meta, Google Analytics, Google Ads, Google Tag Manager, TikTok, LinkedIn, Pinterest, and Snapchat.

“Not detected” does not prove a pixel is absent. Browser checks wait five seconds and do not accept cookies. Tag Manager is a container, not a tracking pixel.
